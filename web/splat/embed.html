Embed a battlefield in your canvas

Give the canvas a CSS width and height. Each instance owns its renderer and listeners, and keeps the supplied element in place. Controls and camera input can be toggled independently. Pass controlsContainer to place optional controls in a host-owned sidebar or overlay; otherwise they use the canvas parent in normal flow. The renderer does not reparent the canvas or change its host layout.

import { createBattleViewer } from "/web/splat/js/battle_viewer.mjs";
const battle = createBattleViewer({ canvas, controls: false, cameraControls: false });
const unsubscribe = battle.onEvent(event => console.log(event.type));
await battle.load("/web/splat/scenes/64bb46d5.json");
battle.setControlsVisible(true);
battle.setCameraControlsEnabled(true);
battle.setTokens([{ id: "hero", kind: "player", cell: [c, r], anim_seq: 1 }]);
battle.follow("hero");
battle.effects({ shake: { amplitude_px: 8, duration_ms: 200 } });
// When the host view unmounts:
unsubscribe(); battle.dispose();

load() accepts a profile URL, profile object, PLY, SOG or LOD manifest URL. Relative assets in fetched profiles resolve from the profile URL; inline objects resolve from the host document or baseURL. Failed loads reject and emit an error; superseded or disposed loads reject with AbortError.

APIPurpose
send / setTokens / setCamera / followApply ordered authoritative scene snapshots or individual presentation commands.
setGridVisible / setCharactersVisible / setVisibleToggle scene layers and canvas visibility.
effects / setEffectsEnabled / setColorGrade / setLOD / pauseControl presentation; effects may omit seq for an automatic sequence.
getState / onEvent / resize / disposeRead detached state, subscribe with an unsubscribe callback, resize and release owned resources.

onEvent() emits loading, ready, state, tokens, scene, stats, error and disposed. Events include a detached state snapshot; ready includes the filtered grid. Errors carry code and detail. setTokens(), setCamera() and effects() return false for stale sequenced commands. Malformed token/camera sequence arguments throw; invalid effect commands return false. Automatic sequences share the same counters as explicit game commands.

dispose() is idempotent: it removes owned controls, input and resize listeners, releases renderer resources and restores managed styles. The host canvas remains in place and can be mounted again. A canvas can have one active battle renderer; use separate canvases for independent instances. This renderer requires WebGL2. Hosts can read attribution from getState().source. createBattleRuntime() in battle_runtime.mjs exposes the same scene API without any control-panel code.

Tokens use valid supported cells from getState().grid. Token paths omit the starting cell and require an advancing anim_seq. Explicit scene, camera and effects sequences reject stale updates. Use send({v:1,type:"scene",seq,visible,tokens,camera}) for game snapshots. The example supplies local stand-ins; the API does not choose game moves.
